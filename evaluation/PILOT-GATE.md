# 真实模型评测的运行条件

当前不追加真实模型试跑。已有少量历史观察见 [试跑结果](PILOT-RESULTS.md)；它们不是独立盲测，也不作为正式质量结论。

## 开始前需要确认

1. 用户明确要求恢复真实评测，并确认发送的源码范围与当前 Agent 模型目的地。
2. 使用 DSH 正常工具权限和新的预览。普通确认不能替代宿主权限，也不能另开模型 API 绕过限制。
3. 固定单个样本的修改前后源码和必要业务契约，不把答案、测试断言或其他实现一起送给模型。
4. 留存插件版本、输入指纹、模型路由、每次调用状态和原始输出。不记录密钥。
5. 安排人工裁决，区分正确候选、额外误报、未完成和无法确定。

## 预算与统计

沿用产品的输入、调用和时间上限。评测目录中的共享调用计数器只是离线辅助，没有集成为多个服务快照的统一运行权限；不能宣称产品支持任意实验总额度。

报告中的调用尝试次数不等于提供方实际计费次数。受控模型响应只用于机制测试，不得混入真实模型成绩。

## 已知限制

已有四组合成输入和一个项目自身历史缺陷，不是外部独立基准。缺少授权、原始输出或人工裁决时，保持未运行或未完成状态，不用新增合成样本代替真实评测。
