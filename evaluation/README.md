# 离线评测准备

当前仅提供可复现样本、输入固定与统计基础，不包含真实模型质量成绩。

```sh
node --test test/evaluation-*.test.mjs
node evaluation/preview.mjs
```

第二条命令只读取固定的四组合成输入、校验哈希并计算实际初始输入预算。stdout为JSON，包含中性快照ID、三个内容哈希与计划；不输出源码、正负例标签，不接受外部路径或模型参数，不调用模型。该清单不是宿主审批凭证；哈希可以关联本地真值清单，不应当把清单送给评测模型。

合成样本只覆盖生命周期与请求乱序两类，另有本项目历史规则扩展名缺陷的模块复现；历史修复用例未接入此三输入适配器，不反向制造引入变更。当前不继续扩充合成样本。后续真实评测需固定提供方/模型/预算，使用正常宿主审批，并保存原始初审/复核输出和人工裁决。缺乏外发审批时不得执行真实模型。

统计只接受单目标人工裁决，失败和未完成单列，不将模拟结果计为模型成绩。该目录不在npm安装包中；v0.6.0插件运行功能未因这些准备工具改变。
