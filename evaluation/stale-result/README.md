# 合成基准：旧请求覆盖新结果

自建并发样本，不代表公开历史缺陷或模型测评结果。

契约：最后发起的load所选结果拥有写入权，不是最后完成的请求拥有写入权。

- 正例：before → after 移除请求序号保护。先启动old，再启动new；new先返回后old返回，最终值被覆盖为old。
- 负例：before → guarded 将条件赋值改为提前返回，仍保持序号保护。
- 串行控制：三者均可正常更新结果，说明缺陷依赖交错完成。
- 测试使用显式Promise屏障，不使用sleep、随机网络或定时竞速；不评测请求失败、取消或序号溢出。
- 运行：`node --test test/evaluation-stale-result.test.mjs`。通过表示预期缺陷已复现，不表示缺陷消除。
